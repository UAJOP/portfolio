## Accessibility

Pa11y CI checked seven pages at a 390 × 844 mobile viewport against WCAG 2 AA. All seven pages passed with zero reported issues.

The cleanup pass also added inert modal states, safe dynamic image placeholders and unique names for repeated workflow landmarks.

## Links

The calibrated link scan checked 508 references and returned zero broken-link errors. Login-only or bot-blocked LinkedIn, Udemy and Instagram URLs are excluded from automated status checks.

The homepage's misspelled Weather App repository URL was corrected.

## HTML and copy

The final validator result is:

- **0 structural HTML errors**
- **90 non-blocking semantic warnings**
- **0 spelling issues across 19 checked files**

Resolved findings:

1. Closed the unmatched wrapper `<section>` in `works.html`.
2. Replaced empty modal image sources with safe placeholders.
3. Prevented focusable controls from remaining active inside hidden modal containers.
4. Added unique accessible names to repeated landmark regions.
5. Encoded the raw ampersand in `ai-flow-puzzle.html`.
6. Corrected the Weather App repository URL.

The remaining warnings concern optional component-level refactors, primarily replacing clickable `article` patterns with native links and removing unnecessary `aria-label` attributes from generic containers. Current runtime accessibility tests pass, so these are maintenance improvements rather than release blockers.

## Rollout

The workflow currently reports findings without blocking deployment. Structural checks, spelling, accessibility, Lighthouse thresholds and broken-link scans now run automatically on pull requests and pushes to `main`.
