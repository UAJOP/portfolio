Privacy Policy

This page explains what data kaanbalci.com and its AI assistant AJOOP handle, and how AJOOP's owner-only, read-only Google and GitHub connectors work.

Last updated: 27 September 2026

Who runs this site

kaanbalci.com is the personal portfolio of Kaan Balcı. AJOOP is the AI assistant built into it: it answers questions about Kaan's projects, experience and skills from the public portfolio content. Kaan Balcı is responsible for both.

What visitors share

  • AJOOP chat: the question you type and the recent turns of the same conversation are sent to AJOOP's service to generate an answer. The service keeps only anonymous, aggregate usage counters; it does not store your messages.
  • Request form: if you send a project request, the details you enter (such as your name, email address, company and project description) are saved to a Google Sheet in Kaan's Google account and emailed to him so he can reply. You also receive a confirmation email.
  • Email: if you write to Kaan directly, your message is used only to reply to you.

Analytics and browser storage

  • The site uses Umami Cloud for cookie-free visit statistics and a few anonymous interaction events, such as opening a project or a contact link. Page addresses are recorded without query strings or fragments, and your browser's Do Not Track setting is respected.
  • There is no advertising and no cross-site tracking.
  • Your theme and language choices are saved in your browser's local storage. AJOOP and Recruiter Mode keep minimal state for the current visit in session storage; AJOOP does not store your messages there.

Google and GitHub connectors (owner only)

AJOOP has private connectors that only Kaan Balcı, as the site owner, uses with his own accounts. Visitors cannot use them, and they never access a visitor's Google or GitHub data.

  • Gmail: read-only access (gmail.readonly) to search and read Kaan's own email. AJOOP cannot send, delete or change email.
  • Google Calendar: read-only access (calendar.events.readonly) to Kaan's own calendar events. AJOOP cannot create, change or delete events.
  • Google Drive: read-only access (drive.readonly) to find and read Kaan's own files. AJOOP cannot create, change, share or delete files.
  • GitHub: used only to read pull request and repository information from Kaan's own repositories, for requests he makes.

How connector data and tokens are handled

  • Data read through the connectors is used only to answer Kaan's own requests inside AJOOP.
  • OAuth and access tokens are used only to provide the connector features described above.
  • Tokens and connector data are never sold, never shared with advertisers and never used for advertising.
  • Tokens are kept in private, access-restricted storage controlled by Kaan and are never committed to public source control.
  • AJOOP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Google API Services User Data Policy

Revoking access

Google access granted to AJOOP can be removed at any time from the third-party access page of your Google Account:

myaccount.google.com/permissions

GitHub tokens can be revoked at any time in GitHub's developer settings.

Service providers

The site is hosted on GitHub Pages. AJOOP's public service is reached through Cloudflare, and its search index is hosted on Qdrant Cloud, which receives a numeric representation of each question rather than its text. Fonts and icons load from Google Fonts and unpkg, and request-form submissions are handled by Google Apps Script. These providers process technical data such as IP addresses under their own privacy policies.
